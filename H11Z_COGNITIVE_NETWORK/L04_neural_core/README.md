# Layer 4: Neural Core & Architectures 🕸️

This layer defines the fundamental computational blocks of the H11 Cognitive Substrate. From individual neurons and synapses to complex mechanisms like Attention, Mixtures of Experts, State-Space Models (Mamba), and Diffusion backbones.

2. H11-SYNAPSE: Synaptic weight binding.
3. H11-WEIGHT: Weight management and lifecycle.
4. H11-BIAS: Bias handling.

6. H11-LAYER: Layer stacking and composition.
7. H11-RESIDUAL: Residual and skip connections.

16. H11-MOE: Mixture-of-experts.

18. H11-HYENA: Implicit long convolutions.
19. H11-RWKV: Linear-attention RNNs.
20. H11-DIFFUSION-NET: Diffusion backbones.

22. H11-OUTPUT-HEAD: Output projections.
23. H11-ARCHITECT: Neural architecture search.
24. H11-PARAMETER: Parameter and FLOP budgeting.
