# H11-CREATIVITY: Creative Cognition

## Overview
H11-CREATIVITY generates novel and valuable ideas using divergent thinking, transformational creativity, and combinational creativity. It leverages techniques like SCAMPER and random stimulation to break out of conventional thought patterns.

## Core Mechanisms
1. **Divergent Thinking**: Generating multiple distinct solutions to an open-ended problem.
2. **SCAMPER Technique**: Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse. Systematically applying these operations to existing concepts.
3. **Combinational Creativity**: Merging two unfamiliar or disparate concepts to produce a novel synthesis (Boden's combinatorial creativity).
4. **Transformational Creativity**: Altering the conceptual space itself to produce thoughts that were previously impossible.
5. **Evaluation (Novelty + Value)**: Creative outputs must be filtered; pure novelty is noise without functional value.

## Algorithms
- Conceptual Blending (Fauconnier and Turner, 1998)
- Divergent semantic search via embedding space interpolation.
- Evolutionary algorithms for idea mutation.

## Dependencies
- NLTK/Spacy (optional, for semantic manipulation)
