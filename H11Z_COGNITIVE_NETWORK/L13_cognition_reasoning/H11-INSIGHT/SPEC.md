# H11-INSIGHT: Insight Generation

## Overview
H11-INSIGHT is responsible for facilitating "aha" moments in cognitive reasoning. It deals with situations where standard analytic processing gets stuck (impasse) and utilizes mechanisms such as constraint relaxation, problem restructuring, and incubation to discover non-obvious solutions.

## Core Mechanisms
1. **Impasse Detection**: Identifies when heuristic search or logical deduction hits a plateau.
2. **Constraint Relaxation**: Temporarily lifts assumed (but unstated) rules to expand the search space (Knoblich et al., 1999).
3. **Problem Restructuring**: Changing the representation of the problem to make a solution apparent (Gestalt psychology).
4. **Incubation**: Background processing and spreading activation over a semantic network while conscious attention is directed elsewhere.
5. **Eureka Detection**: Evaluates whether a sudden structural change provides a valid solution and triggers a positive epistemic emotion.

## Architectures
- **Representational Change Theory (RCT)**: Models the process of insight through chunk decomposition and constraint relaxation.
- **Spreading Activation**: Over associative memory structures to find distant connections.
