resource limits (cgroups), network isolation, filesystem isolation, sandbox escape detection.\n- **H11-ACCESSCTRL** (Access Control): Authorization: RBAC (role-based), ABAC (attribute-based), ACL, OAuth 2.0, JWT tokens, permission hierarchies, least-privilege principle, capability-based security, access policy engines (OPA).\n- **H11-ENCRYPT** (Encryption): Cryptography: AES-256, RSA, elliptic curve, TLS 1.3, encryption at rest/in transit, key management (KMS), homomorphic encryption, envelope encryption, certificate management, crypto agility.\n- **H11-ADVERSARIAL** (Adversarial Defense): Adversarial robustness: adversarial examples, FGSM/PGD attacks, adversarial training, certified robustness, adversarial detection, robustness benchmarks, input perturbation defense, adversarial patches.\n- **H11-INTEGRITY** (Integrity Checks): Data integrity: checksums (SHA-256), Merkle trees, digital signatures, code signing, model hash verification, integrity monitoring, tamper detection, supply chain security, SBOM.\n- **H11-POISON-DEFENSE** (Poisoning Defense): Training data poisoning: backdoor detection (Neural Cleanse, Activation Clustering), data poisoning attacks, model poisoning, federated poisoning, data sanitization, spectral signatures.\n- **H11-PROMPTGUARD** (Prompt-Injection Defense): Prompt security: direct/indirect prompt injection, instruction hierarchy, input/output sanitization, prompt injection detection classifiers, delimiter strategies, system prompt protection.\n- **H11-JAILBREAK-DEFENSE** (Jailbreak Defense): Jailbreak prevention: jailbreak taxonomies, multi-turn jailbreaks, obfuscation attacks, role-play attacks, encoding attacks, jailbreak detection, output filtering, safety training robustness.\n- **H11-PRIVACY-SEC** (Privacy Preservation): Privacy engineering: data minimization, purpose limitation, consent management, privacy impact assessments, privacy by design, GDPR technical measures, right to erasure, data processing records.\n- **H11-DIFFPRIVACY** (Differential Privacy): DP mechanisms: epsilon-delta DP, Gaussian/Laplace mechanisms, DP-SGD, composition theorems, privacy budget management, Renyi DP, local vs central DP, DP for text/embeddings.\n- **H11-FEDERATED-SEC** (Federated Security): Federated learning security: secure aggregation, model update verification, Byzantine-robust aggregation, gradient leakage prevention, federated differential privacy, client selection security.\n- **H11-THREAT** (Threat Detection): Threat intelligence: threat modeling (STRIDE/DREAD), AI-specific threat models, supply chain threats, model theft, data exfiltration, prompt-based threats, threat hunting, IOC detection.\n- **H11-INTRUSION** (Intrusion Detection): IDS/IPS: network intrusion detection, anomaly-based IDS, signature-based IDS, API abuse detection, rate limiting, DDoS mitigation, brute force detection, behavioral analysis.\n- **H11-RESILIENCE** (Resilience Engineering): System resilience: fault tolerance, graceful degradation, bulkhead pattern, circuit breaker, retry with backoff, timeout management, redundancy, resilience testing, blast radius limitation.\n- **H11-CHAOS** (Chaos Engineering): Chaos practice: controlled failure injection, Chaos Monkey, Litmus, game days, steady-state hypothesis, blast radius, chaos experiments, failure mode analysis, chaos in ML systems.\n- **H11-BACKUP** (Backup & Recovery): Backup systems: incremental/differential backup, snapshot-based backup, backup verification, RPO/RTO targets, backup rotation, off-site backup, backup encryption, disaster recovery planning.\n- **H11-IMMUTABLE** (Immutable Logs): Tamper-proof logging: append-only logs, write-once storage, blockchain-based logging, cryptographic chaining, log integrity verification, compliance logging, forensic readiness.\n- **H11-ZEROTRUST** (Zero-Trust Architecture): Zero-trust: never trust/always verify, micro-segmentation, identity-centric security, continuous authentication, device trust, least-privilege access, zero-trust network access, BeyondCorp.\n
