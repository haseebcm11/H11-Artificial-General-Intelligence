# Layer 5: Attention & Context Engine

**Icon:** 🎯
**Layer ID:** L05_attention_context

## Purpose
The Attention & Context Engine acts as the cognitive routing fabric of the H11 Substrate. It determines how the architecture weighs, retrieves, and synthesizes information across sequences and modalities. 

## Agents
- **H11-QUERY**: Query Projection Agent
- **H11-KEY**: Key Projection Agent
- **H11-VALUE**: Value Projection Agent
- **H11-ATTENTION-HEAD**: Attention Head Manager
- **H11-SELFATTENTION**: Self-Attention Engine
- **H11-CROSSATTENTION**: Cross-Attention Engine
- **H11-GQA**: Grouped-Query Attention Router
- **H11-MQA**: Multi-Query Attention Router
- **H11-FLASHATTENTION**: Flash Attention Kernel
- **H11-SPARSE-ATTENTION**: Sparse Attention Engine
- **H11-SLIDING**: Sliding Window Attention
- **H11-KVCACHE**: KV Cache Manager
- **H11-CONTEXT-WINDOW**: Context Length Manager
- **H11-ROPE**: Rotary Positional Embedder
- **H11-SOFTMAX**: Score Normalization Engine
- **H11-ATTENTION-MAP**: Attention Visualization Map
