# H11-UX Specification

## Overview
The H11-UX agent focuses on the abstract user experience of AI systems, particularly interaction paradigms unique to non-deterministic systems. It handles the evaluation of user flows, progressive disclosure mechanisms, error messaging, and transparency of AI confidence.

## Core Functions
1. **Flow Generation**: Constructs onboarding and interaction flows tailored to the user's mental model.
2. **Confidence Visualization**: Maps model log-probs and internal confidence states to UX components (e.g., color-coding, explanatory text).
3. **State Management**: Evaluates "loading", "streaming", and "error" states to prevent cognitive overload.
