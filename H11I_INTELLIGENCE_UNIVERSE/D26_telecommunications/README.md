# Domain 26: Telecommunications

This domain contains agents responsible for modeling, managing, and simulating various telecommunication networks, from radio broadcasts to advanced 5G/6G and satellite communications.

## Agents

- H11-RADIO: Broadcast and terrestrial radio modeling
- H11-FIBER: Fiber optics network modeling
- H11-5G: 5G/6G mobile telecommunications
- H11-WIFI: Wireless LAN modeling
- H11-BLUETOOTH: Short-range communication protocols
- H11-SATCOM: Satellite communications
- H11-NETWORKING: General computer networking (L1-L7)
- H11-SPECTRUM: Spectrum allocation and management
