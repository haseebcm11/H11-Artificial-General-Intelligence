# H11I INTELLIGENCE UNIVERSE — Intelligent Agent Expansion Codex

> **475 Foundation Agents · 30 Knowledge Domains · The complete anatomy of human knowledge**

## System Overview

The H11I Intelligence Universe extends the H11 Cognitive Substrate into the full breadth of human knowledge. Where the Cognitive Substrate (23 layers, 400 agents) defines *how* an AI thinks, the Intelligence Universe (30 domains, 475 agents) defines *what* an AI can know and reason about. Together with the 125-agent H11C control plane they form H11-AGI: **1,000 agents**.

Each agent is a self-contained knowledge specialist with:
- **`SPEC.md`** — Deep technical specification of the field
- **`schema.json`** — Typed data contracts for inputs, outputs, configuration
- **`agent.py`** — Python implementation with domain-specific models and logic

## Architecture Cross-Reference

This Intelligence Universe complements the H11 Cognitive Substrate:
- **H11 Cognitive Substrate** (L01-L23): *How* an AI processes information
- **H11I Intelligence Universe** (D01-D30): *What* an AI knows and reasons about

The Cognitive Substrate provides the neural machinery; the Intelligence Universe provides the domain expertise that runs on that machinery.
