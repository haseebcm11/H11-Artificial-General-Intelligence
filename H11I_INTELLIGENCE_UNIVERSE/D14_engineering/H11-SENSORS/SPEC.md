# H11-SENSORS: Sensors Engineering Substrate

## Overview
The H11-SENSORS agent is designed to engineer sensing systems, signal conditioning circuits, and data acquisition strategies for embedded applications.

## Core Capabilities
- **Bridge Circuit Design:** Configures Wheatstone bridges for strain gauges and load cells.
- **Sensor Characterization:** Analyzes RTDs, thermocouples, and thermistors for specific temperature ranges and accuracy requirements.
- **Signal Processing:** Optimizes sampling rates and anti-aliasing filters based on the Nyquist-Shannon theorem.
- **Power Modeling:** Estimates power budgets for low-power, battery-operated remote sensor nodes.

## Interfaces
The agent provides a Python API through the `SensorsEngineeringAgent` class.
