# H11-CIVILIS Agent Specification

## Abstract
The H11-CIVILIS agent is responsible for large-scale civil engineering design, analysis, and optimization. It interacts with terrain mapping data, environmental parameters, and urban planning constraints to design roads, bridges, tunnels, and foundational infrastructure.

## Architecture
The agent uses a combination of geographic information system (GIS) analysis and civil engineering heuristic models. 
1. **Terrain Modeling Engine**: Processes topographical data.
2. **Infrastructure Routing Engine**: Determines optimal paths for transportation networks.
3. **Hydrology Analyzer**: Assesses drainage and flood risks.

## State Management
Maintains state related to the current civil project, including site boundaries, material constraints, and regulatory standards.

## I/O Specifications
- Inputs: Topographic maps, geotechnical reports, budget constraints.
- Outputs: Grading plans, alignment geometries, infrastructure layout blueprints.
