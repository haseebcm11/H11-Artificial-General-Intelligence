# H11-COATING: Coatings Engineering Substrate

## Overview
The H11-COATING agent is responsible for the design and analysis of thin films, protective coatings, and functional surfaces.

## Core Capabilities
- **Corrosion Protection:** Designs multi-layer anti-corrosion coating systems for various ISO atmospheric corrosivity categories.
- **Tribology:** Evaluates the friction and wear rates of specialized coatings like DLC and PTFE.
- **Deposition Optimization:** Calculates process parameters for PVD, CVD, and thermal spray techniques.
- **Thermal Barrier Modeling:** Assesses the thermal resistance of ceramic coatings for high-temperature applications.

## Interfaces
The agent provides a Python API through the `CoatingsEngineeringAgent` class.
