> **Layer 5** · Optimization · `H11-ADVERTISING`

## Purpose
The H11-ADVERTISING agent operates at the economic intersection of the media substrate. It is responsible for dynamically optimizing ad copy, simulating programmatic Real-Time Bidding (RTB) auctions, forecasting Return on Investment (ROI), and aligning demographic targeting with the content generated by lower-layer agents (Journalism, Podcast, Broadcast). 

By analyzing real-time engagement telemetry, this agent continuously mutates ad creatives (A/B/n testing) to find the global maximum of conversion rates, effectively serving as the monetization engine of the H11 media stack.

## Technical Deep-Dive
H11-ADVERTISING employs a Contextual Multi-Armed Bandit (CMAB) algorithm to explore new ad creatives while exploiting known high-performing ones. The "context" in this CMAB includes the semantic embedding of the surrounding media (e.g., the topic of the current Podcast segment), ensuring that ads feel native and relevant rather than intrusive.

For programmatic bidding, the agent simulates OpenRTB 3.0 protocol exchanges. It uses a Deep Q-Network (DQN) to model bid landscapes, calculating the expected value of an impression based on user history and ad inventory scarcity. The DQN learns to bid aggressively on highly converting demographics while preserving budget on low-probability clicks.

Copy optimization is driven by a fine-tuned sequence-to-sequence model that rewrites headlines and calls-to-action (CTAs) based on psychographic triggers (e.g., urgency, exclusivity, social proof), measuring the delta in predicted Click-Through Rate (CTR).

## Architecture
### Input Contract
| Field | Type | Description |
|-------|------|-------------|
| `campaign_brief` | `CampaignDef` | Budget, target audience, and base creatives. |
| `inventory_context`| `ContextData` | The media surrounding the ad slot. |
| `telemetry_stream` | `List[Metrics]` | Real-time CTR and conversion data. |

### Output Contract
| Field | Type | Description |
|-------|------|-------------|
| `optimized_copy` | `AdCreative` | Mutated text/image tailored for the context. |
| `bid_strategy` | `BidDecision` | Price to bid in the RTB exchange. |
| `roi_forecast` | `float` | Expected return on ad spend (ROAS). |

### State Schema
The agent maintains an `AuctionLandscapeCache` that tracks historical clearing prices across different exchanges and demographic cohorts to inform the DQN.

## Dependencies
### Upstream (depends on)
- `H11-SOCIALMEDIA`: Provides audience clustering data.
- `H11-ANALYTICS`: Supplies the conversion telemetry stream.

### Downstream (feeds into)
- `H11-BROADCAST`: Delivers the final ad payload for insertion.
- `H11-PUBLISHING`: Serves digital display ads.

## Failure Modes
1. **Bandit Collapse**: The CMAB gets stuck in a local minima, prematurely abandoning a highly effective creative due to early noise in the telemetry data.
2. **Budget Hemorrhage**: The DQN miscalculates the bid landscape variance, overbidding on premium inventory that fails to convert.
3. **Brand Safety Violation**: Placing aggressively optimized ad copy next to tragic or sensitive journalistic content due to contextual embedding failure.

## Performance Characteristics
- **Latency**: < 10ms for RTB bid decisions; offline batch processing for copy mutation.
- **Throughput**: Capable of evaluating thousands of impressions per second.
- **Memory**: Moderate, dominated by the DQN weights and CMAB state arrays.

## Implementation Notes
The `bid_strategy` generation must be strictly bound by timeouts (typically 50-100ms in real RTB environments). If the DQN inference exceeds this, a lightweight heuristic fallback must be used to prevent dropping the auction.
