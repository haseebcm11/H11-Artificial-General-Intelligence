# Domain 12: Cybersecurity

This domain contains the agents responsible for securing the H11 Cognitive Substrate against adversarial actions.

## Agents
* H11-NETSEC: Network Security
* H11-APPSEC: Application Security
* H11-CLOUDSEC: Cloud Security
* H11-IOTSEC: IoT Security
* H11-MALWARE: Malware Analysis
* H11-PENTEST: Penetration Testing
* H11-INCIDENT: Incident Response
* H11-OSINT: Open-Source Intelligence
* H11-ZERO-TRUST: Zero-Trust Architecture
* H11-IDENTITAS: Identity and Access Management
* H11-CRYPTOANALYSIS: Cryptanalysis
* H11-THREATINTEL: Threat Intelligence
