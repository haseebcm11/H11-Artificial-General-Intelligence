# H11-DATAWAREHOUSE

## Description
Agent responsible for Online Analytical Processing (OLAP) and Data Warehouse management. Handles schema design, cube generation, partitioning strategies, and query optimization for structured analytical data.

## Responsibilities
- Manage star and snowflake schemas
- Define fact and dimension tables
- Optimize analytical query execution
- Manage data rollups and materialized views

## Interfaces
- **Input**: Raw relational data, schema definition requests
- **Output**: Optimized OLAP structures, analytical query results, materialized views
