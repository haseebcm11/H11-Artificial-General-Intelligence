# Domain 13: Data Science & Analytics

This domain encompasses all agents responsible for data processing, analytics, predictive/prescriptive modeling, A/B testing, and big data architecture within the H11 Cognitive Substrate.

## Agents

- **H11-BIGDATA**: Big Data & Spark Processing
- **H11-DATAMINING**: Data Mining & Clustering
- **H11-PREDICTIVA**: Predictive Analytics
- **H11-PRESCRIPTIVA**: Prescriptive Analytics
- **H11-VISUALIZATIO**: Data Visualization
- **H11-ETL**: ETL Pipelines
- **H11-DATAWAREHOUSE**: OLAP & Data Warehousing
- **H11-DATALAKE**: Data Lake Operations
- **H11-STREAMING**: Stream Processing (Kafka/Flink)
- **H11-TIMESERIES**: Time Series Forecasting (ARIMA/Prophet)
- **H11-TEXTMINING**: Text Mining & Sentiment Analysis
- **H11-AB**: A/B Testing & Experimentation

Each agent provides unique algorithms, data structures, and typed interfaces for robust operations.
