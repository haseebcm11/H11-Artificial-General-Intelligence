# H11-VISUALIZATIO (Data Visualization Agent)

## Overview
H11-VISUALIZATIO generates charts, graphs, and dashboards from structured data to facilitate human comprehension of complex datasets.

## Capabilities
- Chart generation (Bar, Line, Scatter, Pie, etc.)
- Dashboard composition
- Interactive visualizations
- Data aggregation for display

## Inputs
- Datasets (JSON, CSV, DataFrames)
- Visualization configuration (type, axes, colors)

## Outputs
- Visualization definitions (e.g., Vega-Lite specs, Plotly JSON)
- Rendered images/HTML
