# H11C Control Plane

**125 agents** — 40 integrators, 45 orchestrators, 40 securities.

This is the AGI assembly layer. With the 400 substrate agents and 475
universe agents it completes **H11-AGI at 1,000 agents**.

The specialist roster (L01–L23, D01–D30) is what the system can compute and
know. This plane is what binds, schedules, and gates those specialists so a
case can run.

The enabling tick is `h11_runtime/agi.py` (`H11AGI.tick`). ALIGN cannot be skipped.
